# kmeans-clustering-python
### K-Means clustering implementation in Python using NumPy

Implemented the K-Means clustering algorithm from scratch in Python to group data points based on Euclidean distance in feature space.

- Developed the complete clustering workflow, including cluster assignment, centroid updates, iterative optimization, and convergence checking.
- Calculated the clustering cost using the sum of squared distances between data points and their assigned centroids.
- Tested the implementation on a two-dimensional dataset and analysed the resulting cluster assignments and centroids.
- Strengthened understanding of unsupervised learning, feature-space representations, distance-based clustering, and iterative machine-learning algorithms.
